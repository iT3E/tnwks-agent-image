# The official plugins that a sandboxed session needs as a verified official
# install, not as a plugin from plugins.load.paths: one plugin id and its npm
# package for each line. A sandboxed session uses a web search provider only
# when it is bundled with the product or is a verified official install.
#
# The build puts each package, at the release of the product, in an npm cache
# in the image. The official plugins step of the pod installs it from there
# with the installer of the product, with no network
# (image/install-official-plugins, README "The official plugins").

# the gateway process, not in a sandbox.
